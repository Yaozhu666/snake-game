# 贪吃蛇 · 设计说明

## 1. 概述

本程序是一个基于 Windows 控制台的贪吃蛇小游戏,纯 C 语言编写,仅依赖 Windows SDK
(`windows.h`) 和 MinGW 自带的 `conio.h`,无需第三方库。

## 2. 数据结构

- 蛇身使用两个定长数组存储坐标:`snakeX[]` / `snakeY[]`,`snake[0]` 为蛇头;
- 最大长度 `MAX_LEN = WIDTH * HEIGHT`(蛇填满整个场地即获胜);
- 方向用向量 `dirX / dirY` 表示,避免逐格转向产生的"掉头"问题
  (转向时禁止反向:如当前水平移动时不能直接上下反向)。

## 3. 渲染方式

- 使用 `SetConsoleCursorPosition` 逐格定位绘制,代替 `system("cls")` 整屏清屏,
  避免画面闪烁;
- 每帧只擦除蛇尾、绘制新蛇头,而不是重绘整个画面;
- 隐藏光标(`SetConsoleCursorInfo`)进一步提升观感。

## 4. 游戏逻辑

| 模块 | 说明 |
|---|---|
| `initGame()`   | 初始化蛇的位置、方向、分数,绘制边框并生成首个食物 |
| `spawnFood()`  | 在随机空位生成食物,保证不与蛇身重叠 |
| `handleInput()`| 读取键盘(WASD / 方向键 / 空格 / Q),兼容方向键两字节扫描码 |
| `step()`       | 移动蛇、判断撞墙 / 撞自己 / 吃食物,返回存活状态 |
| `main()`       | 主循环:输入 → 步进 → 绘制 → 延时,死亡后显示结算画面 |

## 5. 难度曲线

每吃 5 个食物(蛇长超过 5 节后),帧间隔减少 5ms,最低降至 50ms,游戏逐渐加快。

## 6. 可扩展方向

- 增加关卡/地图编辑;
- 增加障碍物与加速食物;
- 拆分 `snake.c` 为 `snake.c + snake.h + main.c` 多文件模块(头文件放入 `include/`);
- 移植到跨平台终端(替换 `conio.h` / `windows.h` 为 `ncurses` 等)。
